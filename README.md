# Open-State

Відкрита база законодавчих ініціатив, реформ та проєктів правок.

Мета проєкту: перетворити ідеї на готові до впровадження правові документи за принципом Open Source.

---

## 📂 Структура репозиторію

### ⚖️️ 1. Судова система та захист прав (`/justice`)

Правила гри, баланс сил між людиною та державою, захист від свавілля чиновників.

- [01. Презумпція правоти громадянина](justice/01-presumption/README.md) — захист особи у разі правових колізій та двозначності законів.
- [02. Реформа електронних петицій](justice/02-petitions/README.md) — скасування формальних відписок та обов'язковий розгляд петицій.
- [03. Аудит державних реєстрів](justice/03-register/README.md) — заборона вимагати паперові довідки, якщо дані вже є в базах.
- [04. Місцеві референдуми та ініціативи](justice/04-local-referendum/README.md) — обов'язковість рішень громад та захист від блокування радами.

### 💻 2. Цифрова держава (`/digital`)

Відкриті дані, електронне урядування, автоматизація взаємодії з держорганами.

- [01. Відкриті дані громад та комунального майна](digital/01-municipal-open-data/README.md) — машиночитані реєстри майна, землі та оренди.
- [02. Автоматична дерегуляція (Мовчазна згода)](digital/02-auto-deregulation/README.md) — автоматичне надання дозволів у разі порушення строків держорганами.
- [03. Стандарт відкритих API для реєстрів](digital/03-open-api/README.md) — обов'язковий програмний доступ до державних баз даних.
- [04. Місцеві онлайн-консультації](digital/04-consultations/README.md) — Обов'язкові публічні онлайн-консультації та зворотні зв'язки (feedback loops) перед ухваленням рішень місцевою владою.

### 📈 3. Економіка та дерегуляція (`/economy`)

*(У розробці)* Податкові стимули, зменшення бюрократичного тиску на малий бізнес.

### 🎓 4. Освіта та наука (`/education`)

*(У розробці)* Реформи освітніх стандартів, прозорість фінансування закладів.

### 🏥 5. Охорона здоров'я (`/healthcare`)

*(У розробці)* Прозорість медичних закупівель, права пацієнтів та реформа системи.

## 🛠️ Як влаштований кожен модуль?

Кожна папка з конкретним законопроєктом містить по стандарту 4 файла:

1. `README.md` - навігатор по проєкту.
2. `concept.md` - суть проблеми та рішення по простому.
3. `note.md` - класична пояснювальна записка для представників влади.
4. `draft.md` - юридичний текст законопроєкту чи правок.

## 🤝 Як долучитися?

Якщо ви юрист, розробник, експерт або просто людина, яка бачить конкретну системну проблему - пропонуйте свої рішення через Pull Requests або створюйте нові модулі за аналогічною структурою.

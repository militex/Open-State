# ПОЯСНЮВАЛЬНА ЗАПИСКА

## до проєкту Закону України «Про внесення змін до Закону України „Про доступ до публічної інформації“ щодо забезпечення програмного доступу до державних електронних інформаційних ресурсів (API)»

### 1. Обґрунтування необхідності прийняття законопроєкту

Наявний рівень розвитку відкритих даних в Україні потребує переходу від застарілої концепції «публікації статичних файлів» до сучасних стандартів програмної інтеграції. Відсутність вимоги щодо обов'язкової наявності відкритих програмних інтерфейсів (API) у державних реєстрах ускладнює роботу розробників, аналітиків та антикорупційних організацій, які змушені витрачати ресурси на ручне збирання та обробку масивів інформації.

### 2. Мета і завдання законопроєкту

Метою законопроєкту є модернізація інфраструктури відкритих даних та впровадження сучасних технологічних стандартів прозорості державного сектору.

Основними завданнями акта є:

* законодавче закріплення вимоги щодо розробки та підтримки публічних API для державних електронних реєстрів і систем, що містять публічні дані;
* встановлення єдиних технічних вимог до забезпечення машиночитаного програмного доступу;
* створення умов для розвитку українського ринку цивік-теч та інноваційних проєктів на основі державних даних.

### 3. Загальна характеристика та основні положення законопроєкту

Проєктом пропонується внести зміни до Закону України «Про доступ до публічної інформації», зобов'язавши розпорядників державних реєстрів забезпечити технічну можливість автоматизованого запиту та отримання відкритих даних через стандартизовані програмні інтерфейси (API) без необхідності сплати будь-яких зборів чи проходження дискримінаційних процедур авторизації.

### 4. Фінансово-економічне обґрунтування

Реалізація положень законопроєкту не потребує додаткових видатків із державного бюджету, оскільки розробка та підтримка програмних інтерфейсів є стандартною технічною вимогою під час модернізації або супроводу сучасних баз даних та інформаційних систем.

### 5. Очікувані результати

* Підвищення якості та швидкості оновлення відкритих даних у суспільному просторі.
* Стимулювання створення нових технологічних рішень, додатків та сервісів для громадян і бізнесу.
* Зменшення корупційних ризиків завдяки можливості швидкого та масового аналізу державних масивів даних за допомогою алгоритмів.

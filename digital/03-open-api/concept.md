# Концепт: Обов'язкові програмні інтерфейси (API) для державних реєстрів

## Проблема

Сьогодні відкриті дані в Україні часто реалізуються у вигляді величезних статичних файлів (JSON, CSV або Excel), які треба вручну завантажувати, зберігати на власних комп'ютерах і намагатися обробляти. Держреєстри працюють у закритому режимі, а розробники, журналісти-розслідувачі чи цивік-теч проєкти не мають прямого, безпечного програмного доступу до оновлення даних у реальному часі. Це гальмує створення якісних аналітичних сервісів і моніторингових систем.

## Суть рішення

Запровадити стандарт: кожен державний реєстр або інформаційна система, що фінансується з бюджету та містить публічні дані, зобов'язані мати технічно документизований та безкоштовний публічний інтерфейс (API). Будь-який розробник чи громадська організація отримують легальну можливість підключитися й автоматично отримувати зміни в даних без ручних завантажень.

## Ключові принципи

1. **Дані як сервіс (Data-as-a-Service):** Державні бази мають працювати за сучасними IT-стандартами, а не як склади старих файлів.
2. **Рівний доступ для всіх:** API має бути загальнодоступним, без дискримінаційних платних ліцензій чи штучних перешкод для громадянського суспільства.
3. **Безпека за замовчуванням:** Програмний доступ надається виключно до публічної частини даних із дотриманням стандартів кібербезпеки та захисту персональних даних.
